# Muhammad Shafeeq - Portfolio

A premium, production-ready portfolio website showcasing full-stack development expertise.

## 🚀 Overview

This is a custom-built, high-end portfolio that breaks away from traditional developer portfolio templates. It presents an immersive engineering experience designed to showcase production-ready web systems and full-stack capabilities.

## ✨ Key Features

- **Interactive Architecture Visualization** - Dynamic system architecture diagram showing full-stack connections
- **Production Systems Showcase** - Detailed case studies of 4 real production applications
- **Premium Dark Theme** - Sophisticated design with cyan and violet accent colors
- **Fully Responsive** - Optimized for all devices from mobile (320px) to 4K displays
- **Smooth Animations** - Purposeful, performant animations with reduced-motion support
- **Perfect Accessibility** - Semantic HTML, keyboard navigation, ARIA labels, and WCAG compliance
- **SEO Optimized** - Complete meta tags, Open Graph, and structured data
- **Fast Performance** - Optimized images, code splitting, and lazy loading

## 🛠️ Tech Stack

- **Framework:** React 19.1.1
- **Build Tool:** Vite 7.1.7
- **Styling:** Tailwind CSS 4.1.13
- **Icons:** Lucide React
- **Font:** Inter (Google Fonts)

## 📦 Installation

```bash
# Clone the repository
git clone <your-repo-url>

# Navigate to project directory
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 🔧 Customization

### Update Personal Information

Edit the following files:
- `src/components/HeroSection.jsx` - Name and title
- `src/components/AboutSection.jsx` - Profile and education
- `src/components/ExperienceSection.jsx` - Work experience
- `src/components/ProjectsSection.jsx` - Projects
- `src/components/SkillsSection.jsx` - Skills
- `src/components/ContactSection.jsx` - Contact details

### Change Colors

Primary accent colors are defined throughout components:
- **Cyan:** `#06b6d4` - Primary accent
- **Violet:** `#8b5cf6` - Secondary accent
- **Dark Background:** `#0a0a0a`
