# Muhammad Shafeeq - Portfolio

A high-performance, SEO-optimized portfolio website built with modern web technologies.

## 🚀 Features

- **Smooth Scrolling**: Powered by Lenis for buttery smooth scroll experience
- **Performance Optimized**: 
  - Code splitting and lazy loading
  - Optimized scroll event handling with RAF throttling
  - GPU-accelerated animations
  - Content visibility for better rendering
- **SEO Optimized**:
  - Comprehensive meta tags (Open Graph, Twitter Cards)
  - Structured data (JSON-LD Schema.org)
  - XML Sitemap and robots.txt
  - Semantic HTML structure
- **Responsive Design**: Mobile-first approach with Tailwind CSS
- **Accessibility**: WCAG compliant with keyboard navigation and ARIA labels

## 🛠️ Tech Stack

- **Framework**: React 18
- **Build Tool**: Vite
- **Styling**: Tailwind CSS v4
- **Smooth Scroll**: Lenis
- **Icons**: Lucide React
- **Language**: JavaScript (ES6+)

## 📦 Installation

```bash
# Clone repository
git clone https://github.com/shafeeq-3/portfolio.git

# Navigate to directory
cd portfolio

# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 🎯 Performance Optimizations

### Smooth Scrolling
- Lenis library for smooth scroll
- RequestAnimationFrame for scroll events
- Transform-based animations for better performance

### Code Splitting
- React lazy loading for route-based code splitting
- Manual chunk splitting for vendors
- Dynamic imports for heavy components

### CSS Optimizations
- CSS containment for better rendering
- Content visibility for off-screen elements
- Will-change hints for animations
- GPU acceleration for transforms

### Image Optimization
- Lazy loading images
- Content-visibility for better LCP
- Preconnect to font CDNs
